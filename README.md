# Πρόβλεψη αποχώρησης πελατών με νευρωνικά δίκτυα

Η εργασία αυτή έγινε στο πλαίσιο του μαθήματος *Neural Nets & Deep Learning* (AI105) του University of Derby. Το ερώτημα που μελέτησα ήταν αν ένα νευρωνικό δίκτυο μπορεί να προβλέψει ποιοι πελάτες μιας εταιρείας τηλεπικοινωνιών θα αποχωρήσουν και πόσο καλά τα καταφέρνει σε σχέση με μια απλούστερη μέθοδο, τη λογιστική παλινδρόμηση.

[Άνοιξε το notebook με την ανάλυση, τα γραφήματα και τα αποτελέσματα](./Neural_Nets_Analysis.ipynb)

## Πώς δούλεψα

Ξεκίνησα εξετάζοντας στοιχεία όπως η διάρκεια συνεργασίας του πελάτη με την εταιρεία, το είδος του συμβολαίου και η μηνιαία χρέωση. Αφού προετοίμασα τα δεδομένα, χρησιμοποίησα τη λογιστική παλινδρόμηση ως σημείο αναφοράς για τις δοκιμές που ακολούθησαν.

Στη συνέχεια εκπαίδευσα ένα πολυεπίπεδο νευρωνικό δίκτυο (MLP), δοκίμασα dropout και L2 regularisation και χρησιμοποίησα το Optuna για την επιλογή υπερπαραμέτρων. Στην τελική σύγκριση συμπεριέλαβα επίσης τα Random Forest και XGBoost. Με το SHAP εξέτασα ποια χαρακτηριστικά επηρέαζαν περισσότερο τις προβλέψεις του νευρωνικού δικτύου.

## Τι έδειξαν τα αποτελέσματα

Η τελική αξιολόγηση έγινε σε 1.057 πελάτες. Για να συγκρίνω τις προβλέψεις των μοντέλων, χρησιμοποίησα κοινό κατώφλι ταξινόμησης 0,50. Οι μετρικές precision, recall και F1 αφορούν τους πελάτες που αποχώρησαν. Το ROC-AUC υπολογίστηκε από τις πιθανότητες που έδωσε κάθε μοντέλο.

| Μοντέλο | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0,8108 | 0,6884 | 0,5267 | 0,5968 | 0,8447 |
| MLP με Optuna | 0,7947 | 0,6441 | 0,5089 | 0,5686 | 0,8414 |
| Random Forest | 0,7985 | 0,6753 | 0,4662 | 0,5516 | 0,8399 |
| XGBoost | 0,7985 | 0,6683 | 0,4804 | 0,5590 | 0,8423 |

Στον συγκεκριμένο διαχωρισμό δεδομένων, η λογιστική παλινδρόμηση είχε το υψηλότερο F1 και ROC-AUC. Αυτό που ξεχώρισα ήταν η διαφορά ανάμεσα στη συνολική ακρίβεια και στον εντοπισμό των πελατών που μας ενδιαφέρουν. Το μοντέλο ταξινόμησε σωστά περίπου το 81% όλων των πελατών, αλλά εντόπισε μόνο το 53% όσων τελικά αποχώρησαν. Στο notebook εξετάζω επίσης πώς αλλάζει η ισορροπία ανάμεσα στο precision και το recall όταν μετακινείται το κατώφλι απόφασης.

## Πώς να τρέξεις την εργασία

1. Κατέβασε και αποσυμπίεσε το [Telco Customer Churn dataset από το Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn).
2. Δημιούργησε έναν φάκελο `Dataset` δίπλα στο notebook και τοποθέτησε το CSV στη διαδρομή `Dataset/WA_Fn-UseC_-Telco-Customer-Churn.csv`.
3. Η εργασία εκτελέστηκε με Python 3.12.1. Από τον φάκελο του αποθετηρίου, σε macOS ή Linux, τρέξε τις εντολές:

   ```bash
   python3.12 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

4. Άνοιξε τον φάκελο στο VS Code με τις επεκτάσεις Python και Jupyter. Άνοιξε το `Neural_Nets_Analysis.ipynb`, επίλεξε το `.venv` από το **Select Kernel** και πάτησε **Run All**.

Το notebook περιλαμβάνει τα σχόλια και την ερμηνεία των αποτελεσμάτων στα ελληνικά.
